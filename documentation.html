Documentation

How to use the USGS Earthquake Explorer web application

Application Purpose

This website lets anyone search, filter, sort, and look into any recent earthquake information. It was created by me, Chris Robayo, for the CSC 225 course Final Project.

How To Use The Website
  1. Open the Search page.
  2. Choose any start date, end date, minimum magnitude, and API order.
  3. Click Search to fetch earthquake data.
  4. Use the place filter, tsunami filter, or local sort to change how the results will show.
  5. Click View Details to open a second page with more information about any single earthquake.
API Information

This website uses the official USGS Earthquake Catalog API, so no API key is needed for this.

Endpoint 1: Query

This query endpoint returns earthquake events in GeoJSON format.

https://earthquake.usgs.gov/fdsnws/event/1/query

Endpoint 2: Count

The count endpoint returns the number of earthquakes that match whatever the user searched.

https://earthquake.usgs.gov/fdsnws/event/1/count

Details Page

The Details page uses the query endpoint again with an event id to request a specific earthquake.

User Interaction With Data
  • Filtering by the date range and the minimum magnitude
  • Ordering by the time or magnitude
  • You can locally filter the text by the place name
  • Filter for tsunami advisories
  • Sorting by the place, depth, or significance
