# USGS Earthquake Explorer
This website lets anyone search, filter, sort, and look into any recent earthquake information.
It was created by me during the 2026 Spring Term, for a Web Dev course Final Project.
It uses two endpoints to fetch the requested data.
It offers a wide variety of options for dynamic sorting on the Earthquake Data, including but not limited to: Filtering by date, filtering for tsunami advisories, sorting by place, depth, or significance.
